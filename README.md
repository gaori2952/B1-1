# README

## 프로젝트 소개

본 프로젝트는 **LLM을 활용한 강의자료 기반 시험 대비 학습 정리 시스템**을 설계하고 검증한 프로젝트입니다.

동일한 강의자료와 프롬프트를 여러 LLM에 적용하여 성능을 비교하고, 최종 모델을 선정한 뒤 대학생 시험 준비를 돕는 학습 코치 **조교**의 시스템 프롬프트를 설계하였습니다.

또한 Few-shot, 단계적 처리 방식, 환각 방지 규칙, 문맥 유지 규칙을 적용하고 실제 대화를 통해 동작을 검증하였습니다.

---

## 주요 과업

* ChatGPT 5.5, Claude Sonnet, Gemini 3.6 비교
* 강의자료 기반 시험 대비 학습 정리 과업 정의
* 학습 코치 **「조교」** 페르소나 설계
* v1 → v2 시스템 프롬프트 개선
* Few-shot 예시 3개 구성
* 환각 검증 질문 5개 테스트
* 10턴 이상 대화를 통한 문맥 유지 검증
* Custom GPT 및 학습 인포그래픽 제작

## 최종 결과

모델 비교 결과 **ChatGPT 5.5**를 최종 모델로 선정하였습니다.

단순 요약 프롬프트에서 발생할 수 있는 자료 밖 추측과 불규칙한 출력 문제를 개선하기 위해, 강의자료를 최우선 근거로 사용하는 **v2 시스템 프롬프트**를 설계하였습니다.

최종 시스템은 자료에 없는 내용을 임의로 생성하지 않고, 불확실한 내용은 `확인 필요`로 표시하며, 대화 중 조건이 변경되더라도 기존 문맥을 유지하도록 구성하였습니다.
